XRNI M8 / Disting NT Converter

This package contains the runnable Python application source and its required assets.
Build-system components have been removed.

OUTPUT FOLDERS
At startup:
  Converted/M8/
  Converted/Disting NT/

M8 mode:
  Produces the joined sliced WAV workflow for Dirtywave M8.

Disting NT mode:
  Keeps all XRNI velocity layers.
  Exports each multisample as a standard WAV:
    - PCM 16-bit
    - 44,100 Hz
  Creates the Poly Multisample JSON preset.
  Places the JSON and sample directory side by side in:
    Converted/Disting NT/

The Disting NT sample files use the note/velocity naming generated by the converter.

Disting NT output layout (JSON and WAV folder side by side):
  Converted/Disting NT/Instrument.json
  Converted/Disting NT/Instrument/Instrument_C3_V1.wav
The Poly Multisample timbre folder matches the WAV folder name.
All Disting NT WAVs are 16-bit PCM at 44,100 Hz.
